# 案例与证据

[English](README.en.md) · [手册首页](../00-index.md)

案例必须是公开安全、可复现或明确标注证据强度的真实产品路径。截图和 Agent 自述不能
单独证明交付完成。

- [Product Fanout 真实 E2E](../18-product-fanout-real-e2e.md): 维护者/QA 验证路径。
- [Autoresearch Campaign](../autoresearch-campaign.md): 多场景长期评估。
- [v0.0.1 Release Notes](../../releases/v0.0.1.md): 已发布能力、边界和首发证据摘要。
- [README Product Tour](../../../README.zh-CN.md#产品导览): Dashboard、Channel、Kanban Agent 和飞书演示。

新增案例应同时记录目标、固定 revision、运行方式、证据、失败/降级和不能推出的结论。
