# Showcases And Evidence

[中文](README.md) · [Manual home](../00-index.en.md)

A showcase must be public-safe, reproducible, or explicit about evidence
strength. Screenshots and agent claims do not prove delivery by themselves.

- [Product fanout real E2E](../18-product-fanout-real-e2e.en.md): maintainer and QA validation path.
- [Autoresearch campaign](../autoresearch-campaign.en.md): multi-scenario long-horizon evaluation.
- [v0.0.1 release notes](../../releases/v0.0.1.en.md): shipped capabilities, boundaries, and launch evidence.
- [README product tour](../../../README.md#product-tour): Dashboard, Channel, Kanban Agent, and Feishu walkthrough.

New cases must record the goal, pinned revision, execution path, evidence,
failure/degradation, and conclusions the evidence does not support.
