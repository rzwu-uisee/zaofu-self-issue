01 · PROJECT NATIVE

02 · REAL PTY

03 · OBSERVE

04 · TAKEOVER

B 主动 Take over；A 立刻失去写权限，双方继续看到同一个响应。

05 · OFFLINE

控制端断网后，服务端 PTY 与 Codex 不退出，观察端收到延迟任务结果。

新客户端恢复同一 Session

全新 browser context 使用同一 Project 与权限重新连接，恢复完整历史与控制。
