## v0.0.7

v0.0.7 focuses on **real Coding Agent PTYs in the browser, recoverable multi-client control, and
per-Terminal usage evidence isolated from Workflow budgets**. Users can start or resume native Codex,
Claude Code, and other TUI sessions from the Dashboard. ZaoFu owns Project, authentication, Session,
and usage boundaries; Herdr owns the real PTY, terminal state, and controller arbitration.

```text
Current Project effective Provider configuration
  -> token-gated Web Terminal action
  -> Project-scoped Terminal Session + one-time WebSocket ticket
  -> Herdr named session / PTY
  -> real Coding Agent CLI

Terminal bytes / screen state
  -> ephemeral interaction plane
  -/> canonical Task / Workflow / Gate truth
```

> **Default behavior change:** `runtime.web_terminal.enabled` now defaults to `true` on the Dashboard
> host, exposing Project-scoped, bounded read projections and capability probing. Every mutation and
> attachment-ticket issuance remains authenticated. It does not install Herdr, start a Provider
> automatically, widen target-Project permissions, or turn terminal content into business truth. An
> unqualified dependency returns a typed unavailable result. A host can opt out explicitly with
> `false`; disabling removes the Web capability but does not terminate an already-running CLI.

## Highlights

### 1. A real Coding Agent Terminal inside the Dashboard

- The Dashboard top bar opens an on-demand Terminal. xterm.js and its resources load only on first
  use. The UI supports default fullscreen, a resizable native bottom dock, light/dark themes, and a
  narrow-screen layout.
- One Project can own multiple isolated Terminal Sessions. Each tab has its own PTY, Provider,
  generation, and usage identity. Switching tabs neither unmounts xterm nor reconnects the WebSocket,
  and output never crosses sessions.
- The New Session menu is derived from the initialized Project's effective orchestrator/role backends.
  A single-Provider Project shows only its Provider; a mixed Project shows multiple Providers. There
  is no second terminal-only allowlist.
- Sessions start with semantic names such as `Codex 1` and `Claude Code 1`. An authenticated Rename
  first updates the Herdr tab label, then atomically persists the display name under the registry lock
  without changing the PTY or usage identity.
- Closing the drawer, browser, or UI tab only detaches. Only an explicit `Stop CLI` terminates that
  Terminal Session.

### 2. Observe, Control, Take over, and reconnect

- A Terminal Session accepts multiple observers but only one controller at a time. Use Observe for
  read-only sharing, Control for input, and an explicit Take over to replace a lost controller. Host
  policy, mutation authentication, and a receipt gate takeover.
- WebSocket attach uses a one-time, short-lived ticket scoped to Project, Session, and mode. A client
  establishes its baseline from a full frame before consuming contiguous delta sequence numbers. A
  bounded-queue overflow closes only that slow connection; after reconnect, the client recovers from
  another full frame without blocking the PTY or other clients.
- After browser refresh, drawer reopen, or client-network loss, a client can reattach to the same Herdr
  Session and restore full screen history. The sharing showcase proves that Codex continues while the
  controller is offline and that a fresh client can recover; it does not claim Dashboard, Herdr, or
  host-crash recovery.
- Project registry, cwd, Herdr named session, and Terminal registry remain Project-isolated. A stale
  browser Project selection falls back to a current Workspace Project instead of continuing requests
  against a deleted object.

### 3. Per-tab usage, cost, and Provider evidence

- Structured Claude Code and Codex transcript usage binds to immutable
  `project_id + terminal_session_id + generation + provider_session_id`. The mutable tab name is only a
  display label, so Rename, refresh, repeated reconciliation, and multi-browser attach do not duplicate
  charges or cross-account usage.
- Terminal usage is recorded in a separate `terminal-cost.jsonl`. The Agents page lists Provider,
  model, context, tokens, cost, and precision per `Interactive Terminals` row. It never enters Workflow
  `cost.jsonl` or affects Task/Run budget gates.
- When no unique Provider session, structured usage, or qualified reader exists, the UI reports
  `awaiting usage`, `unsupported`, or unavailable instead of manufacturing `$0`.
- Qualification on one Linux x86_64 host covers Herdr `0.8.2` and Codex CLI `0.148.0` for a real TUI, `/status`,
  interaction, per-tab usage/cost, and explicit Stop. Claude Code `2.1.233` has a verified real-TUI
  startup and retained blocked session, but returned `Login expired`; Claude usage/cost therefore
  remains credential-blocked. OpenCode and Pi do not yet have signed real-Provider and usage-reader
  qualification for this release.

### 4. Explicit host-security and authority boundaries

- `runtime.web_terminal.enabled` defaults to `true` and can be set explicitly to `false` in the
  Dashboard host's `zf.yaml`. Host policy owns the backend, Herdr binary, minimum version, takeover,
  and resource limits. A target Project cannot widen those permissions.
- Create, rename, attach, takeover, stop, and reconcile first resolve a registered Project and pass the
  existing token/passcode/trusted-session mutation authentication. The browser cannot submit an
  arbitrary executable, cwd, argv, or environment.
- The mutation trust domain of the current action token or passcode trusted session is the entire
  Dashboard instance, not a per-Project ACL. Project-scoped means Session, registry, cwd, and receipt
  isolation; it does not grant each Project independent authorization. Mutually untrusted Projects or
  users require separate OS users, containers, VMs, or hosts.
- The Provider child environment removes `ZF_*` control-plane variables whose names contain a `TOKEN`,
  `PASSCODE`, `SECRET`, or `ENCRYPT_KEY` marker, plus the enumerated Claude/Codex parent session/thread,
  `CODEX_CI`, and nested-entrypoint controls. Ordinary Provider credentials permitted by host policy
  remain available.
- Terminal bytes, ANSI screen state, and TUI text do not enter EventLog, Task, Workflow, or required
  artifacts, do not automatically create Trace/Span, Delivery, Loop, or Graph facts, and cannot advance
  Kernel state through screen scraping. A Provider's native transcript may still exist. ZaoFu's usage
  reader parses the relevant JSONL line by line but extracts and projects only usage, model, timestamp,
  and identity fields; it does not persist prompts, replies, tool bodies, or terminal character streams
  into the Terminal usage ledger or project them into Web/API. A Herdr named session supplies PTY
  capability; it is neither an OS sandbox nor a second ZaoFu orchestration state machine.

## Upgrade Notes

1. **Resolve the version sequence first:** Python and Web remain `0.0.2`, while v0.0.3 through v0.0.6
   remain drafts. Align metadata, lockfiles, tags, and earlier-draft status before publishing v0.0.7.
2. **Update dependencies and static assets:** run `uv sync --extra dev --extra web`,
   `npm --prefix web ci`, and `npm --prefix web run build`, then restart ZaoFu Web.
3. **Install and pin Herdr:** install Herdr `>=0.8.0`, recording the exact release, binary SHA256, and
   host qualification. Do not auto-download or silently upgrade it at runtime.
4. **Confirm the default-on policy:** Web Terminal defaults on, but missing dependencies only produce
   unavailable status. If the host must not expose Terminal, explicitly Stop affected Sessions while
   the capability is still enabled, then set `runtime.web_terminal.enabled: false` and restart Web.
   Disabling directly does not terminate an already-running CLI.
5. **Protect remote access:** use a long-lived action token or passcode session behind a trusted network
   and HTTPS. A Herdr named session is not a multi-tenant OS sandbox.
6. **Qualify each Provider separately:** install and authenticate the CLI selected by the current
   Project's effective backend. A Codex receipt does not qualify Claude Code, OpenCode, or Pi.
7. **Preserve truth boundaries:** use Terminal for an interactive Coding Agent TUI. Advancing a Task or
   Workflow still requires events, artifacts, and controlled actions, never inference from screen text.

## Known Limitations and Release Blockers

1. **Version metadata is not updated:** Python and Web remain `0.0.2`, and v0.0.3 through v0.0.6 have no
   formal public tags.
2. **The capability remains partial:** current qualification covers the core and a Codex slice on one
   Linux x86_64 host. macOS/Windows, the full crash/IME/long-output matrix, and more host combinations
   remain unqualified.
3. **Provider qualification is asymmetric:** a Codex startup, interaction, and usage slice is signed
   off on one Linux x86_64 host; Claude usage is blocked by login state; OpenCode and Pi lack
   real-Provider and structured-usage evidence for this release.
4. **Recovery has a bounded claim:** browser or device disconnect can reattach to a Herdr Session, but
   host reboot is not guaranteed to preserve the same physical PTY. The sharing video is not proof of
   Dashboard or Herdr crash recovery.
5. **Terminal is not a durable transcript system:** full character streams do not enter EventLog or an
   artifact by default. Business results that require audit must use an existing controlled evidence
   path.
6. **Usage depends on structured Provider evidence:** unsupported, unauthenticated, or ambiguously bound
   sessions report unavailable/unsupported. Current cost is a projection from structured usage and the
   Pricing Catalog, not a Provider invoice, and missing evidence must not be interpreted as zero usage.
7. **The complete suite retains a classified baseline red:** full deterministic runs in the task records
   repeatedly reproduce the same SIM1 immutable-`base_commit` assertion against an untouched baseline.
   It is not a Terminal regression, but its owner must resolve or explicitly accept it before formal
   publication; a closure with that node deselected is not a claim that the complete suite is green.
8. **Developer Preview:** Web/API, Terminal protocol, Provider capability, and interaction contracts may
   still change incompatibly before 1.0.

truth or a second orchestrator. Explicit Project, authentication, Session, controller, Provider, and
usage boundaries give the browser Terminal an operable, recoverable, and diagnosable foundation.
