## 版本概览

v0.0.4 收口 v0.0.3 后的四组运行时能力：Task Pipeline / Orchestrator Agent 控制、
Provider 成本与 Long-Horizon 恢复、Task Contract Authority，以及 Kanban Agent
turn 级可观测性。

本版本仍是 Developer Preview。语义判断由 Agent、Skill 和 Prompt 负责；Kernel
继续负责 schema、currentness、CAS、lease、dispatch、证据存在性和外部副作用边界。

## 发布亮点

### 1. Task Pipeline 与 Orchestrator Agent 控制

- 增加 Task Pipeline orchestration runtime、Task workspace、Stage Worker、
  dispatch/recovery/rework/terminal 路径和 Task Pipeline Web 投影。
- 增加 Orchestrator Agent admission、briefing、typed decision、Plan adoption、
  semantic failure 和受控 operation 模块。
- Controller profile 新增 v4 canary / OA pilot 配置；默认生产路径仍保持受控，不隐式切换。

### 2. Provider 成本、预算与 Long-Horizon 恢复

- 增加 pricing catalog、billing calculator、provider usage reconciliation 和 Web cost
  投影。
- hard budget 下无法定价的 usage fail-closed，避免把未知成本当作零成本继续 dispatch。
- 增加 Long-Run Truth、Recovery Case、manual evidence gate、retention inventory、
  self-repair lifecycle 和 no-progress 收敛路径。

### 3. Task Contract Authority

- 增加 Task authority schema、TaskStore CAS 和 `TaskContractAuthorityService`。
- TaskAttempt、dispatch、Impl/Verify、Candidate、Judge 和 terminal closure 绑定当前
  execution target；stale write、stale result 和旧 verification receipt fail-closed。
- 增加 task contract authority doctor 和真实 Provider A/B 支持脚本。

### 4. Kanban Agent Turn 可观测性

- Kanban Agent turn 增加 ephemeral delta bus、首 token/上下文/provider timing 和 terminal
  timing payload。
- Web 侧增加 Kanban interaction policy，避免 stale UI selection 改写 Plan 后端绑定。
- Workflow inspection、Task projection 和 Orchestrator panel 增加更明确的运行边界回读。

## 升级说明

1. 从 release checkout 重新安装依赖并确认版本：

```bash
uv sync --extra dev --extra web
npm --prefix web ci
uv run zf --version
```

预期：

```text
zf 0.0.4
```

2. 不要隐式切换试点执行路径：

- Task Pipeline v4 仍应通过显式 canary/shadow/profile 启用。
- Orchestrator Agent semantic control 仍应通过 allowlist pilot 启用。
- 切换 profile 应启动 fresh Run，并保留旧 Run 的 artifact、attempt 和 recovery evidence。

3. 启用成本预算前先确认 pricing catalog：

```bash
uv run zf cost
uv run zf cost --by-instance
uv run zf cost --by-backend
```

## 已知限制

- Developer Preview 阶段的 Python API、Web API、event schema、Controller profile 和部分
  CLI 仍可能在 1.0 前不兼容变化。
- Task Pipeline v4 和 Orchestrator Agent semantic control 仍是受控试点，不是无条件默认路径。
- 真实 Provider、真实 Feishu 和浏览器环境验证依赖目标租户、凭据和运行环境，仍由 release
  operator 执行。
- Retention inventory 当前是只读/计划能力，不会自动删除运行时证据。
